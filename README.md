# SimGames

🕹️ **Simple Python Games Collection**

This repository contains a collection of beginner-friendly Python games I created as part of my learning journey. Each game is implemented using basic Python, with no external dependencies. These are great for anyone new to Python or looking to understand how simple games work through command-line interaction.

---

📦 **Included Games**

calc.py – A simple calculator that performs basic arithmetic operations (+, –, ×, ÷).

weatherlocation.py – A fun script that randomly assigns weather conditions to fictional locations.

rockapersescissor.py – A classic Rock-Paper-Scissors game to play against the computer.

watergun.py – A variation of Rock-Paper-Scissors, with the twist of Water-Gun-Snake!

slumdog millionaire.py – A basic quiz game inspired by Slumdog Millionaire.

---

🚀 **How to Run**

Clone the Repository:
   ```bash
   git clone https://github.com/<your-repo-name>.git
   cd dengshi
   ```
**Run any game using Python:**

```bash
   python3 game_name.py
   ```
**For example:**

```bash
   python3 calc.py
   ```

📚 **Requirements**

These games require only Python 3. No additional libraries needed.
